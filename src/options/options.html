Alpha setup

Alpha setup: paste a Zoho Mail access token and it is held in memory for this Thunderbird session. Nothing is written to disk, and it is gone when Thunderbird restarts.

Get an access token from the Zoho Mail API with any OAuth client that has ZohoMail.accounts.READ, ZohoMail.messages.READ and ZohoMail.messages.UPDATE scopes; see docs/getting-an-access-token.md.
