Spam Report for Zoho Mail

Unofficial extension. Not affiliated with or endorsed by Zoho Corporation.

Zoho accounts

Connect a Zoho Mail user once. The refresh token is stored in Thunderbird's built-in password manager and access tokens renew automatically. You can connect more than one Zoho user; mailboxes from all of them get the report buttons.
